# Contributing Guide

These guidelines outline the required steps for contributing.

## Docker Images

Docker images must retain licenses and proper credits regarding other docker images, eggs, services, etc.

Docker images must be tested and built, both via docker and via a Pterodactyl Panel. If this docker image needs changes to an egg file, outline those clearly.

## Eggs

Eggs must be exported from a Pterodactyl Panel. Manually changing eggs without testing is not valid.

Eggs must retain licenses and proper credits regarding other docker images, eggs, services, etc.

## AI Disclosure Notice

This repository does not reject AI contributions. However, they must be disclosed within pull requests / issues, and the submitter must have an understanding of what they are submitting.

AI will be treated as a tool, not the full person.

## Questions

If you have questions or concerns, refer to the [README.md](/README.md) file for additional information and contacts. You are free to open an issue for general questions.
